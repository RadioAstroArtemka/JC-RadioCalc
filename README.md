# JCJENSON

**Радиолюбительский калькулятор в одном HTML-файле.** Антенны, кабели, фильтры, спутники, единицы, КСВ и диаграммы направленности. Без установки, без зависимостей и без интернета.

*English: a single-file ham radio toolkit that computes antenna dimensions, coax loss, bandpass filters, satellite Doppler shift, RF unit conversions, SWR and radiation patterns. Open `index.html` in any browser.*

Оформление строгое: красный, белый, чёрный, без градиентов. Тёмная тема включается автоматически по настройкам системы.

## Возможности

| Раздел | Что считает |
|---|---|
| **Антенны** | Полуволновый диполь, V-диполь (длина плеч, расстояние между концами, высота концов), четвертьволновый штырь с радиалами, отрезки кабеля λ/4 и λ/2 с учётом коэффициента укорочения |
| **Конструктор антенн** | До 8 полуволновых элементов с произвольными положением, амплитудой и фазой. Идеальная земля или свободное пространство. Усиление в дБи, направление максимума, ширина луча по уровню −3 дБ, подавление заднего лепестка, азимутальная и вертикальная диаграммы |
| **Коаксиальный кабель** | Потери по типу кабеля, частоте и длине. Дополнительные потери от КСВ нагрузки, КСВ на входе, мощность в антенне |
| **Полосовые фильтры** | Баттерворт и Чебышев, порядок 2–7, значения L и C по звеньям, нагрузочная добротность, подавление на заданной частоте |
| **Доплер для спутников** | Сдвиг для приёма и поправка для передачи для круговой орбиты, таблица по углам места |
| **Конвертер единиц** | Вт, мВт, дБм, дБВт, В, мВ, мкВ, дБмкВ, дБмВ, S-метр, дБ в разы, dBi и dBd, частота и длина волны |
| **КСВ и согласование** | Из КСВ, потерь возврата, коэффициента отражения, прямой и отражённой мощности или импеданса нагрузки R+jX: потери на рассогласование и доля отражённой мощности |

## Быстрый старт

1. Скачайте `index.html` (или `jcjenson.html`).
2. Откройте его двойным щелчком в любом современном браузере.


## Методика расчётов

- **Диполь и штырь:** L = 150·k / f для полной длины диполя, 75·k / f для четвертьволнового штыря (f в МГц, длина в метрах). По умолчанию k = 0,95 для диполя и штыря, 0,93 для V-диполя. Коэффициенты зависят от провода, высоты и окружения, поэтому после монтажа подстройте антенну по анализатору.
- **Кабель:** затухание масштабируется от значения на 100 МГц по корню из частоты. Потери с учётом КСВ: η = a(1 − ρ²) / (1 − a²ρ²), где a — потери кабеля в разах, ρ — коэффициент отражения нагрузки.
- **Фильтры:** синтез по низкочастотному прототипу с преобразованием в полосовой. Средняя частота — геометрическая от краёв полосы.
- **Доплер:** Δf = f · v_r / c. Лучевая скорость для орбиты высотой h: v_r = v · R · cos(e) / (R + h), где e — угол места.
- **Диаграммы:** векторная сумма полей полуволновых диполей, для земли используется метод изображений. Усиление D = 4π·U_max / ∮U dΩ (для земли интегрирование по верхней полусфере).

## Ограничения

- Взаимное влияние элементов в конструкторе не учитывается. Токи в элементах задаёт пользователь, так что для директоров и рефлекторов Яги подставляйте токи из программы моделирования (например, 4nec2 или MMANA).
- Земля идеальная, реальные потери и отражения от неё не считаются.
- Затухание кабелей в пресетах типовое, ориентируйтесь на данные производителя.
- Доплер считается для круговой орбиты без учёта вращения Земли.

Результаты расчётов — инженерные оценки, итоговую настройку всегда выполняйте измерениями.
